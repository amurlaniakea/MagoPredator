repomapper

Herramienta que dado un repo, genera automaticamente el mapa de subsystems, tests, workflows. Muy practico,aplicable a cualquier coding agent y logras un ahorro de más del 95% en tokens por cada interacción inicial, haciendo que tus consultas con LLMs sean muchísimo más baratas, rápidas y precisas.

Repositorio

dock-confidence

A post-hoc calibration layer for molecular docking poses. Estimates calibrated P(RMSD < 2A) and computes Expected Calibration Error (ECE) to filter decoys in drug discovery.

Repositorio

astrocp

Conformal Prediction para clasificación multi-clase con incertidumbre condicional por clase en astronomía (AD-MCP sobre MAPIE). Gap: no existe librería mantenida de CP para clasificación con cobertura condicional por clase en astro. AGPL-3.0-or-later.

Repositorio

materials-confounding-check

CLI that applies the Clever Materials falsification test to materials-science ML datasets: detects confounding via a bibliographic fingerprint (year/author/journal leaking the target). Built on Jablonka 2026 (arXiv:2602.17730) + Huang&Cole / Nandy datasets (Scientific Data).
